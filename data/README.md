# Data

This folder contains raw and processed datasets for EV analysis.

## Folder Structure

```
data/
  raw/                        # Original source data (do not modify)
  processed/                  # Cleaned and transformed data
    merged_charging_station/  # Merged station datasets
    metrics/                  # Calculated metrics for dashboard
    year_2024_processed/      # 2024 gap-filling metadata
```

## Raw Data

| File                          | Description                                | Source                                                                                      |
| ----------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `IEA Global EV Data 2024.csv` | Global EV sales and stock data (2010-2024) | [Kaggle](https://www.kaggle.com/datasets/patricklford/global-ev-sales-2010-2024)            |
| `ev_stations_2025.csv`        | International charging stations            | [Kaggle](https://www.kaggle.com/datasets/risheepanchal/global-ev-charging-stations-dataset) |

## Key Columns

### IEA Data

- `region`: Country or region name
- `category`: Historical or Projection
- `parameter`: Metric type (EV sales, EV stock, etc.)
- `mode`: Vehicle type (Cars, Buses, Vans, Trucks)
- `powertrain`: BEV or PHEV
- `year`: Data year
- `value`: Numeric value
- `unit`: Measurement unit

### Charging Stations

- `id`: Unique identifier
- `title`: Station name
- `country`: ISO country code
- `lat`, `lon`: Coordinates
- `operator`: Station operator
- `status`: Operational status
- `num_connectors`: Number of charging ports
